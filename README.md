# 岸途 · 公考备考

面向公务员笔试的轻量备考 Web App（移动优先）。

## 功能

- **行测训练**：言语 / 数量 / 判断 / 资料 / 常识分模块刷题
- **每日一练 & 迷你模考**：抽题练习，即时解析与得分
- **错题本**：答错自动收录，答对自动清除
- **申论练笔**：材料 + 作答要求 + 本地草稿 + 参考提纲
- **学习进度**：考试倒计时、连续打卡、正确率（本地存储）
- **每日提醒**：自定义提醒时间；到点未打卡时站内横幅 +（授权后）浏览器通知

## 开发

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
npm run preview
```

## 技术栈
